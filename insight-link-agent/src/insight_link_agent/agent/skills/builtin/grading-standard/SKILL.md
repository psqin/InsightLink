# 导师长期评分标准

## 先确定用户要做什么

查看标准、修改标准、恢复默认，与“按我的标准给这份材料打分”是不同任务。按现有标准评价材料用draft_evaluation，复杂任务可交评价与沟通专家；不用索要新的标准，也不能覆盖已有配置。引用、假设、否定和仅本次要求不写长期配置。

## 查看与变更

1. 调用 `get_grading_standard`，读取当前标准、来源和版本。未自定义时工具返回系统默认标准。
2. 仅在本轮冻结授权为save时调用 `set_grading_standard`；局部修改先保留未改变的维度，提交完整新版和刚读取的expected_version。
3. 维度满分合计100分。导师只改一个权重导致总分冲突时，请其明确剩余分配，不自行重分配。
4. 明确恢复默认时，用 `reset_grading_standard` 和当前版本；版本冲突后重新读取，不覆盖其他页面的新配置。
5. 以工具的真实返回说明保存或恢复结果。评分标准是永久配置，不存入一般记忆，不索要学生或材料编号；本操作不会修改任何学生正式成绩。
