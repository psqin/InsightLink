# 学生资料与留言查询

1. 用户给出姓名或学号时，先调用 `search_my_students`。同名学生超过一位时，要求提供学号，不能擅自挑选。
2. 确定学生后，调用 `get_student_profile` 读取学校、学院、专业、班级和入学年份。
3. 查询留言时调用 `get_message_history`，注意它按页返回，未读完时不要声称已看完全部记录。
4. 只回答用户问到的字段；后端未提供的字段要说明无法确认。

## 整班和全体学生

导师要求查看全班、各班或全部学生时，自主调用 `list_my_students`，无需逐一索要姓名。
不填筛选表示当前登录导师指导的全体学生，不是全校学生；可按系统实际班级名称或专业筛选。
默认优先每页100条，按 `next_page` 连续查询至 `has_more=false`，并确认 `complete=true`。
`complete` 仅表示底层授权数据扫描完整，不能省略其余逻辑页。数据变动、重复页或达到扫描预算时，
如实说明已读取范围，不能把部分人数说成总人数。班级不明确时可先查看花名册中的班级名称。
当前花名册列表未提供学院筛选能力，可按班级或专业查询，不得编造学院归属。
