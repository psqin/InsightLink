# 导师记忆检索

1. 当前对话历史是 HOT；系统提供的偏好和近期任务摘要是 WARM，仅作表达习惯参考。
2. 需要回顾更早的导师偏好或任务类别时调用 `read_memory`，不要凭聊天窗口未显示的内容猜测。
3. COLD 情节只记录去敏的任务类别，不包含学生姓名、学号、分数、材料正文或附件。不能把它当作 Java 业务事实；成绩和材料仍须调用授权 MCP 现查。
4. `remember` 只接受导师明确提出的长期回复或评价偏好。不要保存任何学生数据、token、网页内容或模型推断。
5. 若没有检索结果，直接说明未找到相关记忆，不要编造旧会话细节。
